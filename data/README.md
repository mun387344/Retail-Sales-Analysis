Dataset


Source
UCI Machine Learning Repository — Online Retail Dataset


Dataset: https://archive.ics.uci.edu/dataset/352/online-retail


Description:
This project uses the UCI Online Retail dataset, which contains transactional data from a UK-based online retailer between December 2010 and December 2011.



Each row represents a product within a customer transaction.

The dataset includes:
- Invoice number
- Product code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country
  

Purpose
I will use this dataset to analyze sales performance, revenue trends, product performance, and customer behavior.
